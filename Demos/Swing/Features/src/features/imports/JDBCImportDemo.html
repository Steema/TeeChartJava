The Series datasource method can retrieve data from a JDBC database and automatically add it to the series. This example creates a small H2 in-memory database with sample category sales; no external database is contacted. Add H2 2.2.224 to the runtime classpath to run it.

Example:
Connection c = DriverManager.getConnection("jdbc:h2:mem:teechart");
Statement s = c.createStatement();
ResultSet r = s.executeQuery("SELECT CategoryName, CategorySales FROM CategorySalesDemo");
series.getYValues().setDataMember("CategorySales");
series.setLabelMember("CategoryName");
series.setDataSource(r);
s.close();
c.close();
