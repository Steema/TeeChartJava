Tutorial 3 - 챠트 페이징

차트에서 데이터 소스가 차트 화면에 명료하게 디스플레이 될 수 있는 것보다 더 많은 데이터를 가지고 있다면, 차트를 페이지들로 나누어 페이지를 넘겨볼 수 있도록 만들고 싶어질 것입니다. 차트 에디터나 프로그램을 이용하면 이것을 가능하게 할 수 있습니다.

차트 에디터로 페이지하기

페이지의 크기는 차트 에디터를 가지고 정의할 수 있습니다. 사용자가 에디터를 가지고 페이지를 바꾸기 위해서는 프로젝트에 페이지 버튼을 추가하거나 당신의 프로젝트에 차트 에디터를 실행시에 사용가능하도록 해 주어야 합니다.

디자인타임시에 차트 에디터에서 Paging 탭을 선택하십시오. .

In the Points per Page: box, 상자에서, 차트 페이지에서 보고자 하는 시리즈 포인트의 개수를 입력 또는 스크롤해서 넣어줍니다. 만약 시리즈를 위해 데이터 값을 코딩하고 있다면, 검색 버튼은 당신이 프로젝트를 실행시키고 시리즈를 채운 후 실행시에 차트 에디터를 보이게 하기 전까지는 검색 버튼은 강조되지 않을 것입니다. 만약 당신이 데이터소스를 연결했다면 디자인타임에 즉각 페이지 효과가 나타나는 것을 볼 수 있습니다.

실행시:

챠트 에디터를 통하여 실행시에 페이징 속성에 접근하려면 EditChart 또는 EditDBChart 메소드를 사용합니다.

예제 (당신의 프로젝트에 EditChart와 Editpro를 사용하는데 필요합니다.)

EditChart(self, Chart1);


코드로 페이징하기

페이지 속성과 메소드는 Page Class를 통해 가능해집니다..

챠트에 페이징추가하기 위한 요구단계:

  1. 페이지 당 포인트를 설정

    2. 페이지당 최대 포인트를 사용하여 각 페이지마다 디스플레이 되는 포인트의 개수를 정의하십시오.

    예제

    tChart1.setMaxPointsPerPage := 10;

     

  2. 챠트폼에 네비게이션 버튼 추가하기.

    3. 예제:

    첫번째 페이지 

    tChart1.getPage().setCurrent(1);

    다음 페이지

    tChart1.getPage().next();

    이전페이지 가기

    tChart1.getPage().previous();

    마지막 페이지

    tChart1.getPage().setCurrent(tChart1.getChart().getNumPages());
  3. 마지막 페이지로 무엇을 할 것인지를 결정하십시오.

    4. 마지막 페이지는 다른 차트 페이지의 포인트 수량에 정확히 일치되는 수를 가지지 못하는 경우가 많습니다. 마지막 페이지의 규모를 선택하고 축 규모도 이에 따라 조정하여 페이지에 남아있는 수를 "최적화" 할 수 있습니다. 아니면 마지막 페이지도 앞의 페이지들과 마찬가지로 같은 수의 포인트를 가지도록 할 수 있으며 이는 만약 마지막 페이지에 많은 포인트가 남아있지 않다면, 마지막 페이지는 차라리 비어 있게 할 수도 있습니다.

    tChart1.getPage().setScaleLastPage(false);   (default = True)

  4. 페이지 번호를 사용자에게 보여주기

    5. TTchart의 OnPageChange 이벤트는 사용자에게 존재하는 페이지 번호를 보여주는데 사용할 수 있습니다. 여기서는 페이지 번호에 라벨을 사용합니다.:

    jLabel1.setText(String.valueOf(tChart1.getPage().getCurrent())+ " of " + String.valueOf(tChart1.getChart().getNumPages()));
