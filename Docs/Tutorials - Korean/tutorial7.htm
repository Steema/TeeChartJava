TeeChart Pro의 함수는 수학 함수는 일종의 시리즈로, 대부분의 시리즈 유형을 포함하며, 그것은 수학적 함수가 적용되거나 다른 차트의 데이터소스 이다.

모든 함수는 Teefunction 클래스에서 파생되며 TeeFunction의 Period 속성 을 상속합니다.

TTeeChart Pro는 다음 목록에 나오는 것과 같은 미리 정의된 함수를 제공합니다. Please see the TeeChart Editor Gallery and Helpfile for a full list of all Function Types:

몇몇 함수 유형은 오직 입력 시리즈만을 지원합니다. 그렇지만 함수들을 연결시키는 것은 가능합니다. 예를 들어 당신의 차트에서 몇몇 시리즈의 평균을 가지고 평균 함수 시리즈를 만든 후, 추이 함수에 입력시키는 것으로 평균 함수를 사용하여 평균의 추이를 알아내는 것 등입니다.

함수 추가하기 (Adding a Function)

차트에 새로운 시리즈를 추가하는 것과 마찬가지로 차트 에디터를 가지고 처음 차트 페이지에서 Add 버튼을 선택하십시오. 필요한 함수를 선택하기 위해 TeeChart 갤러리에서 함수 탭을 고르십시오. 각각의 함수는 선 시리즈로 나타나며, 함수와 관련된 시리즈 유형은 나중에 첫번째 차트 페이지에서 Change 버튼을 가지고 바꿀 수 있습니다. 함수 정의는 나중에 함수 시리즈의 데이터 소스 페이지에서 쉽게 바꿀 수 있습니다. 다음과 같이 하면, 아주 간단하게 함수의 차트에 추가한 일반 시리즈의 정의를 바꿀 수 있습니다. (함수는 사실 데이터 소스의 정의이지 시리즈 유형의 정의는 아닙니다.)

아래의 이미지는 함수를 에디팅할 때의 데이터 소스 페이지를 보여줍니다. 선 시리즈 (이름은"Series1",제목은 "Average") 가 정의 되어있습니다. 데이터 소스 페이지의 아래쪽에 있는 왼쪽 목록 상자는 입력이 가능한 차트 안에 있는 다른 시리즈들을 보여줍니다. (여기서는 "Series0")


완전히 비어있는 차트를 가지고 시작하는 것으로 가정한다면, 코딩으로 차트에 관련된 단순한 시리즈 함수를 만드는 과정은 다음과 같습니다.

private void Load() {

//Add a data Series 
Line line1 = new Line(tChart1.getChart());

//Populate it with data (here random) 
line1.fillSampleValues(10); 

//Add a series to be used for an Average Function 
Line line2 = new Line(tChart1.getChart()); 

//Define the Function Type for the new Series 
com.steema.teechart.functions.Average average1 = new com.steema.teechart.functions.Average(); 
line2.setFunction(average1); 

//Define the Datasource for the new Function Series 
line2.setDataSource(line1); 

//*Note - When populating your input Series manually you will need to 
//use the Checkdatasource method 
//- See the section entitled 'Defining a Datasource' 
//Change the Period of the Function so that it groups averages 
//every 2 Points

line2.checkDataSource();
}

데이터소스 정의하기 (Defining a datasource)

앞서의 섹션에서 살펴본 예제는 함수를 코딩으로 채우기 위해 데이터 소스를 사용하는 것을 강조했습니다. 시리즈는 함수를 위해 입력을 정의하고자 데이터 소스를 사용하거나 또는 시리즈 ODBC 데이터 소스를 정의하는데 사용됩니다. (데이터 베이스에 액세스하기에 관련된 자습서를 보십시오)

차트 에디터를 이용하여 함수를 추가하고 나면, 함수 시리즈의 데이터 소스 페이지가 함수 정의 안에서의 포함이 가능한 시리즈의 목록을 보여줄 것입니다. 여기서 시리즈에 적용하고자 하는 함수 유형으로 바꿀 수 있습니다. 그리고 왼쪽 목록 상자인 "Available" 것들"로부터 시리즈를 선택하고 나서 오른쪽 목록 상자인 "Selected" 것들에 추가할 수 있습니다.

코딩에 의한 데이터소스는 Series.Datasource 속성을 사용합니다.

함수 Period

Period은 함수가 순환적으로 적용되는 함수와 교차하는 포인트 범위를 Period로 정의한 함수를 움직이는 데 있어서 중요한 속성입니다.

예제(Example)

다음과 같이 값을 지닌 6 개의 데이타 포인트를 (예를 들어 막대 시리즈의 막대들) 가지고 있습니다:

3, 8, 6, 2, 9, 12

Period 0 (기본값)을 가진 함수 시리즈를 평균이 그려지도록 정의하면 다음과 같습니다:

6.667

Period을 2로 세팅하면 이 함수으로부터의 출력으로 다음과 같은 평균의 3 값을 얻게 됩니다:

5.5, 4, 10.5

이들 값은 각각의 구간 범위 안에서 중앙으로 플롯을 할 것입니다. 예를 들면 입력 시리즈에서 막대 1과 2 사이의 첫번째 값은, 막대 3과 4 사이의 두번째 값 등등입니다.

데이터 소스 페이지에서 적절한 시리즈와 함수를 선택하고 "Options" 탭을 클릭하는 것으로 구간을 정의할 수 있으며 또는 FunctionType을 이용하여 실행시에 Period을 변경할 수 있습니다.

예를 들어 시리즈 2가 있는 곳의 함수 시리즈는 다음과 같습니다:

line1.getFunction().setPeriod(2);

아래의 두 차트는 적용된 Period의 효과를 강조하고 있습니다.

 

Period 스타일(Period Style)

Period은 범위로 정의될 수 있습니다. 이것은 날짜 시리즈를 사용할 때와 "한달" 혹은 "하루" 등과 같은 날짜 단계에서 함수의 "Period"으로 표현하고자 할 때 매우 유용합니다. "PeriodStyle" 속성은 어떻게 "Period"이 표현될 것인가를 컨트롤합니다.

예를 들어 당신은 이제 날짜 소스 시리즈에 있는 표준 "Average" 함수를 사용하고 함수 period를 "one month"로 설정만 하면 "monthly average of sales" 함수를 플롯할 수 있습니다.:

private void Load() {
        //Add in a BarSeries and Average Function at design-time. 
        java.util.Random rnd = new java.util.Random();   
        tChart1.getAspect().setView3D(false);   

        DateTime today = DateTime.getToday();
    
        bar1.getMarks().setVisible(false); 
        bar1.getXValues().setDateTime(true); 
        tChart1.getAxes().getBottom().getLabels().setAngle(90); 
    
        for(int i = 0; i < 60; ++i)  
            today = today.addDays(5); 
            bar1.add(today, rnd.nextInt(100),"",Color.red); 
    
    
        average1.setPeriodAlign(com.steema.teechart.functions.PeriodAligns.FIRST); 
        average1.setPeriodStyle(com.steema.teechart.functions.PeriodStyles.RANGE); 
        average1.setPeriod(30); 
        line1.setDataSource(bar1); 
        line1.checkDataSource();
}

이것은 몇몇 포인트 안에서 결과가 나올 것이며, 각각은 시리즈0 안에서 매 달 별 데이터의 "average"을 보여주게 됩니다.
. 계산 함수가 날짜 구간일 때 소스 Series0 안에서 포인트가 반드시 날짜별로 분류되어야만 합니다. 범위는 또한 날짜가 아닌 시리즈에도 쓰일 수 있습니다: 

for(int i = 0; i < 60; ++i)  
             bar1.add(new Double(i), rnd.nextInt(100),"",Color.red); 
        
        average1.setPeriodAlign(com.steema.teechart.functions.PeriodAligns.FIRST); 
        average1.setPeriodStyle(com.steema.teechart.functions.PeriodStyles.RANGE); 
        average1.setPeriod(6);

매 "6"의 간격 안에서 각각의 포인트 그룹의 평균을 계산할 것입니다.
(X >=6, X < 6 를 가진 포인트는 첫번째 평균으로 계산될 것이며, with X >=6, X < 12를 가진 포인트는 두번째 평균으로 계산되는 등등....).
이것은 매 6 포인트마다 평균을 계산하는 것과는 다른 것임을 주의하십시오.

Period Alignment 속성을 이용하여 함수 포인트를 시리즈 범위 안에서 정렬시키십시오. 아래와 같이 하면 함수 포인트를 월별 구간의 마지막으로 플롯 시키게 됩니다.: 

	average1.setPeriodAlign(com.steema.teechart.functions.PeriodAligns.FIRST); 
	average1.setPeriodStyle(com.steema.teechart.functions.PeriodStyles.RANGE); 
	average1.setPeriod(com.steema.teechart.DateTime.getDaysInMonth(year,month));

Period = Month.TotalDays and PeriodAligns.First
아래에 있는 그림에서 볼 수 있듯이, "average"는 매 달의 마지막에 표시됩니다.

Period = Month.TotalDays and PeriodAligns.Last
이 경우에는 "average"는 매 달의 시작에서 플롯됩니다. .

커스톰 함수 끌어내기 (Deriving custom functions)

새로운 함수 콤포넌트는 새로운 콤포넌트를 함수클래스로부터 불러들여 단순하게 만들수있습니다. (it also can be derived from an existing function ).

TTeeFunction에서 2개의 중요한 가상메소드가 있는데, 새 함수타입을 만들어 오버라이드 할수 있습니다.

1) Function.Calculate: public virtual double Calculate(Series Source,int First,int Last)

2) Function.CalculateMany: public virtual double CalculateMany(ArrayList SourceSeries, int ValueIndex)

계산 메소드는 계산함수에서 사용되는데, 만약 단순히 한개의 시리즈가 데이터 소스일때 입니다. CalculateMany 는 복합적 시리즈의 데이터소스에서 사용되어집니다.

 

예제 : 새로운 SquareSum 함수 만들기

필요한 SquareSum 함수를 ""sum of squares"돌릴것을 결정할수 있습니다.

이 함수는 단일 데이타소스 또는 복잡한 데이터 소스에서 사용할 것 있으며, Calculate 와 CalculateMany 속성을 오버라이드 할것입니다. 

public class SquareSum extends Function {

    public SquareSum() {
     super();
    } 


    public SquareSum(com.steema.teechart.Chart c) {
	super(c);
    }

    public double calculate(Series sourceSeries,
                            int firstIndex,
                            int lastIndex) {
        ValueList v = valueList(sourceSeries);
        if (firstIndex == -1) {
            return v.getTotal();
        } else {
            double result = 0;
            for (int t = firstIndex; t <= lastIndex; t++) {
                result+=Math.sqrt(v.getValue(t));
            }
            return result;
        }
    }



    public double calculateMany(ArrayList sourceSeriesList,
                                int valueIndex) {
        ValueList v;
        double result = 0;

        for (int t = 0; t < sourceSeriesList.size(); t++) {
            v = valueList((Series) sourceSeriesList.get(t));
            if (v.count > valueIndex) {
                result+=Math.sqrt(v.getValue(valueIndex));
            }
        }
        return result;
    }

첫인덱스와 마지막인덱스에서 sum of squares가 계산되는 모든 SourceSeries 포인트에서 "Loop"는 다양하게 사용됩니다.

"ValueList" 속성은 Steema.Teechart.ValueList 명령을 이용하여 끄집어 냅니다. Xvalues 고정한점 값 과 그렇지 않은 YValues 에서 HorizBarSeries와같은 시리즈유형과 함께 class 작업을 만들수있습니다.

"Calulate" 속성은 데이터소스가 단지 한개의 시리즈에서 사용됩니다. 데이터소스가 한개 이상일때는, "CalculateMany" 속성을 불러서 사용합니다.

"CalculateMany" 는 소스시리즈에서 각 포인트에 불러올것이며, 0점에서 시작하고 모둔데이터수의 최소점에서 끝날것입니다.

Calculate와 CalulageMany 사이에 이해는 매우 중요합니다. "Calculate"는 데이터소스가 하나일때 와 이전에 불렀던것이 있을때 부릅니다. "CalulateMany"는 한개의 시리즈보다 데이터소스가 많을때 여러번 불립니다.
