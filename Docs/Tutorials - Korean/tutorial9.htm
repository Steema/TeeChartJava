차트 내보내기 (Exporting Charts)

사용가능한 포맷(Available Export formats)

사용 가능한 내보내기 포맷입니다. 모든 포맷은 파일이나 클립보드나 스트림으로 복사가 가능합니다.
 

이미지 포맷(Image formats)
  • JPEG: JPEGFormat Class
  • GIF: GIFFormat Class
  • PNG: PNGFormat Class
    • 데이터 포맷(Data formats)
  • Text: TextFormat Class
  • XML: XMLFormat Class
  • HTML: HTMLFormat Class
  • Excel: ExcelFormat Class
    • 다른 포맷 (Other formats)
    Tej format은 차트 속성 정보와 옵션으로 차트 데이터를 저장할 수 있는 융통성 있는 포맷입니다. 파일은 작고 (데이터에 따라서 달라집니다) 라이브 클라이언트에 기반을 둔 차트를 업데이트 하는 데 네트워크로 사용하기에 이상적입니다. .
  • TEJ (TeeChart) TemplateExport Class

    • 내보내기 예제(Example export)

    	    try {

    JPEG

    JPEG 파일을 내보낼때 속도와 퀄리티를 위하여 부가적인 매개변수를 갖고있다. 예제폴더에 포함된 JPEG Demo를 보면된다.

    예제

    	    int tmpResult = fc.showSaveDialog(JpegExportDemo.this);
            if (tmpResult == JFileChooser.APPROVE_OPTION) {
                File file = fc.getSelectedFile();
                String tmpName = file.getAbsolutePath();
                if (!ExportUtils.isExtension(file, ExportUtils.JPG)) {
                    tmpName = ExportUtils.replaceExtension(file, ExportUtils.JPG);
                }                
                myChart.getExport().getImage().getJPEG().save(tmpName);
            }

    Compression Quality 비율값 (높은값으로 압축하면 )을 수행하면, 반면에 품질은 더 좋아지긴 하지만 파일의 용량을 더 크게 만들어 주며, 그에 따라 넷트워크를 통한 전송이 더 느려지게 됩니다 ! 당신의 응용프로그램에 적합한 최적의 밸런스를 결정해야 합니다.

    GIF

    티차트에서 GIF챠트이미지를 만든다는 의미를 제공하나, GIF LZW 의 인코드된 이용에 관한 보다 자세한 정보를 원한다면 unisys라이센스를 확인해봐야 합니다. RLE 인코딩을 선택 할경우 Unisys 라이센스를 고려할 필요는 없습니다.

    코드에 의한 예제(Example by code)

                int tmpResult = fc.showSaveDialog(GifExportDemo.this);
            if (tmpResult == JFileChooser.APPROVE_OPTION) {
                File file = fc.getSelectedFile();
                String tmpName = file.getAbsolutePath();
                if (!ExportUtils.isExtension(file, ExportUtils.GIF)) {
                    tmpName = ExportUtils.replaceExtension(file, ExportUtils.GIF);
                }
                myChart.getExport().getImage().getGIF().save(tmpName);
            }

    PNG

    PNG 포맷은 GIF 의 능력도 보유하고 있고 더많은 이득을 포함하고 있습니다. PNG는 GIF의 이미지를 보여줄때 GIF 만큼 진보된 능력을 포함한다. PNG는 GIF에서 이미지를 보여지는 것보다 혁신적으로 능력이 향상 되었습니다; 그것은 네트워크를 통한 연결에서 이미지에 접근할때 더나은 접근을 향상시키고, 디스플레도 강화시켰다.

    예제

                int tmpResult = fc.showSaveDialog(PngExportDemo.this);
            if (tmpResult == JFileChooser.APPROVE_OPTION) {
                File file = fc.getSelectedFile();
                String tmpName = file.getAbsolutePath();
                if (!ExportUtils.isExtension(file, ExportUtils.PNG)) {
                    tmpName = ExportUtils.replaceExtension(file, ExportUtils.PNG);
                }
                myChart.getExport().getImage().getPNG().save(tmpName);
            }

    TeeChart의 'Tej'템플릿과 데이터 내보내기와 불러오기 포맷
    (TeeChart's 'Tej' template and data export/import format)

    Tej 파일들(Tej files)

    Tej파일은 티차트 소유의 템플릿 포멧으로 챠트를 저장하고 그들 데이타에서 Java IDE 에서 .tej 확장자를 갖고 있다. 수정된 챠트 속성은 그 템플릿을 추가할때 새로운 챠트에 추가할때 복제하고 그 템플릿과 함께 저장된다.

    이점(Advantages):

    • Tej 파일은 매우 작은 사이즈라, 모든 케이스에서 순수 그래픽 포맷을 제공하는 이점이 있다.(Quicker).
    • 목표한 차트에 템플릿이 살아있는 동안, 그것의 속성들이 갖고있는것으로 줌과 스크롤 수정 할수있다.
    • Tej 템플릿은 당신의 선택에 따라서 데이터가 임의 적으로 포함된다.

    예제

    	    try {
        	    tChart1.getExport().getTemplate().toFile("/temp/chart1.tej");       
        	} catch (IOException ex1) {
          	    ex1.printStackTrace();
        	}

    불러오기 (Import)

                }


XML을 불러오기 Load from xml:
             try {

                }

    Tej 포맷 파일 가져오기 (Importing Tej format files)

    로컬파일 소스 또는 http 데이타 소스로부터 저장된 Tej file 불러오기

    불러오기 예제(Example Imports)

    예제

    	    import from file 
    	    tChart1.getImport().getTemplate().fromFile("myFile.tej");
    
    or 
    XML.. 
    	    tChart1.getImport().getTemplate().fromXML("myFile.xml");


    or 
    Stream.. 
            try {
                //( 1) Save the template into a Stream...
                ByteArrayOutputStream m = new ByteArrayOutputStream();                 
                myChart.getExport().getTemplate().toStream(m);
                //( 2) Load the template into other Chart...
                copyChart.setChart(copyChart.getImport().getTemplate().fromStream(
                        new ByteArrayInputStream(m.toByteArray())
                ));
                //( 3) repaint the Chart
                copyChart.repaint();
            } catch (IOException ex) {
                System.out.println(ex);
            } catch (ClassNotFoundException ex) {
                System.out.println(ex);
            }
