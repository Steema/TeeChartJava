시리즈 유형

TChart 시리즈 클래스는 모든 시리즈 유형의 공통적인 부모 클래스입니다.

시리즈 클래스 구조(Series Class structure)

TeeChart 타입 라이브러리의 구조에 대한 사전지식으로서, 여기서 시리즈 클래스와 인터페이스에 대해 설명하겠습니다. 아래의 다이아그램는 TeeChart 시리즈 클래스간의 관계를 보여주고 있습니다. 모든 클래스는 일반적인 "시리즈" 클래스로부터 유도되며 "시리즈" 속성과 메서드를 공유합니다. 시리즈(Custom3DSeries, CustomBarSeries, CircledSeries) 로부터 유도된 몇개의 다른 일반적 클래스는 초록색으로 표시되며, 인터페이스가 프로그래밍으로부터 직접 액세스 할 수 없습니다. 그들의 특성은 그들의 후손 시리즈 유형들로 상속됩니다. 모든 유도된 시리즈들은(빨간색으로 되어 있습니다). 당신의 차트에 포함시키기 위해서 TeeChart 갤러리에서 액세스가 가능합니다. 이러한 식으로 유도된 TeeChart 시리즈는, 공통적인 색인 구조를 통해 프로그램으로 액세스 하는 것을 가능하게 해 줍니다. (이 섹션의 후반부에 있는 예제 코드를 보십시오).

색상(Colour)

포인트의 색상은 포인트를 추가할 때 수작업으로 추가시킬 수 있습니다.

예제

tChart1.addSeries(new Bar());
tChart1.getSeries(0).add(50,"oranges", Color.Orange);

또 다른 방법은 TeeChart 상수 clTeeColor를 사용하여, TeeChart가 색상을 할당하도록 일러주는 것입니다. TeeChart는 19가지에 이르는 고유한 색상 중 아직 사용되지 않은 색을 각각의 새로운 시리즈를 위해 선택할 것입니다.
예제

Random rnd = new Random();
    tChart1.getSeries(0).setColorEach(true);
     for(int i = 0; i < 19; ++i) {
         int higher = i + 65;
         tChart1.getSeries(0).add(rnd.nextInt(100));
   }
}

 

시리즈로부터 데이터 포인트 삭제하기(Deleting data points from a Series)

시리즈로부터 포인트를 삭제하기 위해서는 Series.Delete를 사용하십시오.

예제

tChart1.getSeries(0).delete(7);
 //(8th point - Points index start at zero)

Series.Clear clears all points from a Series.

 

Null 포인트를 시리즈에 추가하기(Adding Null points to a Series)

AddNull 메소드를 지원하는 시리즈 유형의 목록을 보려면 시리즈 데니터 추가하기(Adding data to a Series) 테이블을 보십시오. 이름에서 알 수 있듯이, AddNull은 시리즈에 Null 포인트를 추가하게 하여 포인트를 위해 라벨을 정의할 수 있게 해 주지만 이 포인트의 시리즈 안에서는 중단되게 됩니다. 선 시리즈의 경우, 중단 전의 마지막 포인트는 중단 이후의 첫 포인트와 연결되지 않습니다. Series.AddNull 와Series.AddNullXY를 보십시오.

예제

Line line = new Line();
line.addNull();

 

시리즈 유형 차트에 혼합하기(Mixing Series Types on a Chart)

TeeChart Pro는 데이터 시리즈의 배경으로 빈 차트 캔버스를 제공합니다. 이것은 차트 유형이 미리 정의되지 않았음을 의미합니다. 디스플레이 하고자 하는 시리즈 유형의 혼합으로서 필요한 차트 유형을 정의해야 합니다. 몇몇 시리즈 유형은 특화된 본질 때문에 차트에서 다른 시리즈 유형과 혼합한 것은 실행이 불가능합니다. TeeChart는 새로운 시리즈를 추가하려는 시점이 되었을 때 차트 갤러리에서 적합하지 않은 시리즈 유형을 회색으로 나타나게 해서 도움을 줍니다. 한 차트 안에 입력할 수 있는 시리즈의 숫자는 실제로는 제한이 없습니다.

새로운 시리즈 추가(Adding New Series)

A차트 에디터나 (Tutorial 1보기) 코딩을 이용하여 시리즈를 추가합니다.

예제

public void jButton1_actionPerformed(ActionEvent e) {

    Bar bar1 = new Bar(tChart1.getChart().chart);
        bar1.fillSampleValues(10);
    } 
};

시리즈를 위한 축 선택하기(Choose Axes for a Series)

S차트에 추가된 시리즈는 자동적으로 왼쪽과 아래쪽의 축을 관련 축으로 지닙니다. 차트 에디터에서 관련된 시리즈의 시리즈 일반 페이지를 선택함으로서 관련 축을 바꿀 수 있습니다. 위쪽, 왼쪽, 아래쪽, 오른쪽4가지 축이 사용 가능합니다. 축 바꾸기는 다음과 같습니다.:

bar1.setHorizontalAxis(HorizontalAxis.TOP);
bar1.setVerticalAxis(VerticalAxis.RIGHT);

하나 이상의 시리즈가 각각의 축과 관련될 수 있습니다. TeeChart는 축과 어울리는 시리즈에 적합한 최적의 규모를 결정하지만, 당신도 축 규모를 직접 결정할 수 있습니다 (Axis Tutorial보기)부가적인 축을 추가할 수 있으며, 부가적인 축들은 처음의 4 축으로부터 연관되는 규모를 복사할 것입니다. (Additional axes보기).


시리즈 연결하기(Connecting Series)

다른 시리즈를 위한 데이터소스로서 시리즈를 이용할 수 있습니다. 차트 에디터를 이용하여 두 번째 시리즈를 위해 데이터 소스를 세팅함으로서 가능해집니다. 시리즈 탭, 데이터소스 페이지로 가십시오. 콤보박스에서 Function: 를 데이터소스 유형으로 선택하십시오. 가능한 시리즈와 선택된 시리즈 두 목록 상자들이 나타날 것입니다. 현재의 시리즈를 위해 데이터 소스로서 사용하고자 하는 시리즈를 선택하십시오. 그리고 나서 위에 있는 함수라고 제목이 되어 있는 콤보 박스에서 함수 유형으로서의 복사를 선택하십시오. 이러한 방법에서는 다른 어떠한 시리즈의 함수로서 정의될 수 있으며, 함수 유형은 함수 콤보박스에 있는 목록 중 어떠한 것이라도 될 수 있다는 것을 주의하십시오. 아래에 있는 코딩으로도 똑같이 할 수 있습니다. 

public void bFuncion_actionPerformed(ActionEvent e) {
Bar bar1 = new Bar();
bar1.fillSampleValues();
Line line1 = new Line();

com.steema.teechart.functions.Average average1 = new com.steema.teechart.functions.Average();
line1.setFunction(average1);
line1.setDataSource(bar1);
line1.checkDataSource(); 
}

TeeChart 함수들의 사용에 관한 보다 자세한 정보는 tutorial 7 - 함수로 작업하기(Working with Functions) 보십시오


시리즈 순서 바꾸기(Changing Series order)

시리즈 순서를 바꾸는 것은 차트 에디터를 이용하면 상당히 쉽습니다. 에디터의 첫 페이지로 가서 움직이고자 하는 시리즈를 강조하십시오. 오른쪽에 있는 화살표 버튼을 이용하여 시리즈 순서 안에서 시리즈를 위아래로 움직여 보십시오. 시리즈 순서는 다른 시리즈를 고려하면서 차트 안에서 시리즈의 위치를 상대적으로 디스플레이 하도록 결정될 것입니다. 시리즈리스트 속성 또는 변경된시리즈 메소드를 코드로 사용하려면.

Example 
tChart1.exchangeSeries(0,1);  //Change Series(0) with Series(1) in the index order

*주의. 시리즈를 교환한 후에는 시리즈를 위한 색인은 바뀝니다. 위에 있는 코딩 라인들은 만약 코드가 다시 실행된다면, 0이 1이 되고 1이 0이 되도록 2개의 시리즈의 0과 1을 영구히 바꾸어 놓습니다.

시리즈를 'Active=False'로 설정하면 차트로부터 시리즈가 감추어지지만 데이터 내용은 그대로 지니게 됩니다.

시리즈 값 목록(Series Value list)

TeeChart Series store their values in a Valuelist accessible and modifiable via the TChartValueList component.

값 사용하기 예제(Example using Values)

이 코드는 바 시리즈의 바 값을 사용자의 마우스 클릭에 따라 변경해줍니다.

예제

upDatePoint(valueIndex,tChart1.getAxes().getLeft().calcPosPoint(e.Y));

Call the UpdatePoint Sub routine to modify the Bar's value:

private void upDatePoint(int Bar, double Y)
	{ 
		if(Bar < tChart1.getSeries(0).getCount())
		{
			tChart1.getSeries(0).getYValues().setValue(Bar,Y);
			tChart1.paint(tChart1.getGraphics());
		}
	}

시리즈 이벤트(Series events)
 

앞서의 섹션에서 시리즈 이벤트의 몇가지 용법에 대해 소개했습니다. 이 섹션에서는 몇가지 추가적인 용법에 대해 알려드리겠습니다.
 

OnGetSeriesPointerStyle
TChart 포인터를 사용하는 시리즈를 위해서는, OnGetSeriesPointer 이벤트를 사용하면 포인터에 액세스 하여 변경하는 것이 가능합니다.:

Drawing an Uptriangle if the Point is higher than the last, DownTriangle if lower, etc.
 
 
if(e.ValueIndex > 0)  {
            if(line1.getYValues().getValue(e.ValueIndex) > 
               line1.getYValues().getValue(e.ValueIndex - 1))  {                
                e.Style = PointerStyles.TRIANGLE;
            }
            else if(line1.getYValues().getValue(e.ValueIndex) < 
                    line1.getYValues().getValue(e.ValueIndex - 1)) {
                e.Style = PointerStyles.DOWNTRIANGLE;
            }
            else {
                e.Style = PointerStyles.DIAMOND;
            }
        }
        else {
            e.Style = PointerStyles.DIAMOND;
        }


OnGetSeriesMark
OnGetSeriesMark 이벤트를 이용하여 실행시에 표식 내용을 변경할 수 있습니다. 이 코딩은 마지막 화살표 길이가 바뀌는 것에 연관된 값에 따라서 Marktext도 바뀌게 합니다.;
TeeChart 에서 DragMarks 툴을 통하여 오버래핑한 경우에는 Marks의 드래깅을 제공합니다:
 

              
     if(e.ValueIndex > 0)  {
                 if(line1.getYValues().getValue(e.ValueIndex) >
			line1.getYValues().getValue(e.ValueIndex - 1)) {
                     e.MarkText = e.MarkText + " (Up)";
                 }
                 else if(line1.getYValues().getValue(e.ValueIndex) < 
			line1.getYValues().getValue(e.ValueIndex - 1)) { 
                    e.MarkText = e.MarkText + " (Down)";
                 }
                 else {
                     e.MarkText = e.MarkText + " (No Change)";
                 }
             }
         }
